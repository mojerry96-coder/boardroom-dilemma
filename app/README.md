# The Boardroom Dilemma — simulation app

A standalone, responsive React build of the DBA9101 governance simulation.

- Production copy and decisions: `../boardroom_dilemma_replication_package/CONTENT_LOGIC_FINALIZATION.md` (section 19 records the 15 September 2026 corrections)
- Visual and responsive direction: `../boardroom_dilemma_replication_package/BOARDROOM_DILEMMA_MASTER_REPLICATION.md`
- Script and learning logic: the DBA9101 course script (not included in this repository)

## Run

```bash
npm install
npm run dev
```

Other scripts:
- `npm test` covers scoring, formulas and the resolver (including every possible run), and checks that every spoken line has a recording.
- `npm run typecheck`
- `npm run build`

### Useful URL flags (development and QA)

| Flag | Effect |
|---|---|
| `?reset` | Clears the saved session and starts a new run |
| `?store=<name>` | Uses a separate saved session, so QA runs don't overwrite your own |
| `?debug` | Shows hidden state and page jump buttons (never for learners) |
| `?noshuffle` | Keeps option order A–D instead of the per-run shuffle |

## Media

The media is final. How it was generated, the film build script and the voice cast are in `../media/README.md`.

- **Images:** replace a file in `public/scenes/` and adjust its `position` in `src/assets.ts` if the framing changes.
- **Films:** rebuild with `python3 ../media/build_films.py`. The captions come out of that script.
- **Spoken lines:** when a line changes in `content.ts`, re-record it with the same voice and replace its file in `public/voice/`. A line without a recording falls back to browser speech synthesis, and `npm test` lists any line that is missing a file.

## Background score

One looping bed (`public/music/score.webm`, with an MP3 fallback), mastered quiet with a dip through the speech frequencies. `src/sound.ts` holds the whole design:

- **Per page:** a level for each page — loudest on the opening, the crisis, the Board Q&A and the outcome; quietest where the player is reading, listening or writing (evidence desk, stakeholders, Board case).
- **Under speech:** any narrated or spoken line ducks the bed by about 10 dB, and it returns when the line ends.
- **Chapter cards:** a small lift, so each act break lands.
- **Films:** the score stops; films carry their own sound.
- **Starting:** only after the player interacts with the page (browsers require this), and it pauses when the tab is hidden.
- **Player control:** a music button sits next to the audio and captions buttons and is remembered with the other preferences. It is independent — the volume button controls narration and character voices, this one controls the score.

To change the feel, edit the numbers in `src/sound.ts`. To replace the track, drop it in `media/audio/music/` and re-run the loop and mastering commands in `../media/README.md`.

## Loading on slow networks

Full-quality media is always the default. The build adds lighter paths for weak connections:

- **Photos** are served as AVIF (or WebP), sized for the screen, with the original JPEG as a fallback. Visual similarity to the JPEG is 0.98 SSIM or higher. A tiny blurred preview shows while each scene loads.
- **Voice** plays as Opus (about a third of the size of the MP3), falling back to the MP3. Each clip is downloaded once and replayed from memory.
- **Films** start at 720p. With data saver on, on 2G/3G, or when the film stalls for three seconds, the player switches to the 480p rendition and carries on from the same moment. It remembers this for the session.
- **Pages** 2–10 load on demand. Each page's photos, props and recordings, and the next page's code, are fetched in the background, so they are ready when the player arrives. Data saver turns this pre-fetching off.
- **Repeat visits:** a service worker (`public/sw.js`, production only) keeps app files, photos, props, voice and fonts in a local cache. Films always stream from the network.
- **Hosting:** `public/_headers` sets long cache lifetimes (read by Netlify and Cloudflare Pages; copy the rules for other hosts). Bump `VERSION` in `public/sw.js` when media files are replaced.

After replacing a photo, voice line or film, run `python3 ../media/optimise_media.py` to regenerate the lighter versions and the manifests.

## Connecting an LMS or server

Implement `PersistenceAdapter` (`loadSession`, `saveSession`, `clearSession`, `submitResult`) and export it as `persistence` from `src/sim/persistence.ts`. `submitResult` receives the debrief data the script asks for (all choices, allocations, lenses, reform, flags, final state, ending and reflections).

## Voice input

Voice input uses the browser's speech recognition where available; otherwise the microphone is hidden and typing works as normal. Transcripts land in the editable field and nothing submits automatically. A server transcription provider can be added behind the `TranscriptionProvider` interface in `src/components/VoiceField.tsx`. Never put an API key in frontend code.
